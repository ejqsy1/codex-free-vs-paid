# Codex免费版和付费版区别全解析：免费版到底够不够用？Go、Plus、Pro、Business各档差在哪？按API计费更省钱吗？（附完整价格对比表与立减优惠码）

先给结论：Codex 没有“独立的免费版”或“独立的付费版”。这个 AI 编码代理被打包进 ChatGPT 的各个计划里，从 Free 到 Enterprise 全都包含，区别不在“能不能用”，而在额度、云端功能和适用场景。

所以“Codex免费版和付费版区别”这个问题，真正要比的是三条线：ChatGPT Free 计划附带的免费额度、Go 之上的各档付费订阅，以及不订阅、直接用 API key 按 token 付费的路线。下面把这三条线一次讲清楚。

## 先搞清楚：Codex 的计费结构和你想的不一样

Codex CLI 本身开源，免费安装，装上不花钱。真正产生费用的是登录方式：用 ChatGPT 账号登录，消耗的是订阅计划里的额度；换成 API key 登录，就按 API 价格逐 token 计费。

而 ChatGPT 目前的 Free、Go、Plus、Pro、Business、Edu、Enterprise 计划全部附带 Codex，官方没有单独的“Codex 订阅”这个 SKU。换句话说，大家嘴里的“Codex 免费版”，实际就是 ChatGPT Free 计划里那份免费额度；“付费版”则是 Go 起步的各档订阅，或者干脆绕开订阅走 API。

搞清这个结构，后面的对比就好理解了——你选的从来不是“Codex 的版本”，而是“ChatGPT 计划的档位”。

## 免费版能用什么，卡在哪里

免费计划确实包含 Codex，能跑基本的编码任务，也够你完整体验一遍“读代码库、改文件、跑测试、开 PR”的流程。官方对它的定位就是试水：额度给得紧，够摸摸手感，不够日常干活。

几个具体的限制：

- 额度按 5 小时窗口重置，另外可能叠加周上限，免费档同样适用，只是基数更小
- 云端任务委派从 Plus 才开始提供，连 $8 的 Go 都不含，免费版自然没有
- 免费档具体能跑多少条消息，官方没有像付费档那样给出公开估算，以登录后界面提示为准

什么人适合停在免费版：一周打开一两次、改几个小问题、主要想看看这类工具能做到什么程度。一旦你的使用节奏变成“每天都要用”，免费额度基本撑不过一个上午。

### Go（$8/月）：从免费到付费的最小一步

### Plus（$20/月）：大多数开发者的默认档

官方对 Plus 的描述是“每周几次专注的编码会话”。这是多数每天写代码的人的起点档，云端任务委派从这一档开始解锁。

额度方面有个很实用的参考。Codex 目前跑在 GPT-5.6 系列模型上，分 Luna、Terra、Sol 三档，额度消耗差距很大：用最轻的 Luna，Plus 每个 5 小时窗口大约能跑 250 到 2000 条本地消息；换成 Terra 掉到 25 到 200；最重的 Sol 只有 10 到 100。另外，本地会话和云端任务共用同一份额度，云端跑多了，本地的窗口余额也会变少。

### Pro（$100–$200/月）：全职重度用户

Pro 5x 每月 $100，额度是 Plus 的五倍；Pro 20x 每月 $200，二十倍。官方的说法很直白：Plus、Edu 和 Business 席位覆盖的是“每周几次专注会话”，而 Pro 能支撑“整个工作周、多个项目”。用 Luna 模型时，Pro 5x 每个 5 小时窗口的估算区间是 1250 到 10000 条本地消息，差不多是 Plus 的五倍量级。

## 额度到底怎么算：5 小时窗口、周上限和模型档位

订阅额度按 5 小时窗口滚动重置，部分情况还会叠加周上限。自 2026 年 4 月起，Codex 的用量按积分（credits）计算，一个积分对照官方 API 费率折算大约 4 美分。

任务之间的消耗差异非常大。官方帮助文档给的参考是：一个典型任务消耗 5 到 45 积分，小修小补通常只要 5 到 15，大型重构则可能吃掉一大块周额度。顺带提醒，这些参考数字是按 GPT-5.5 给出的，而 GPT-5.5 将于 10 月 14 日从所有计划退役，之后的消耗基准会随新模型调整。

想省额度，最便宜的一招是精简 AGENTS.md。这个指令文件会在每次任务里重复加载，写得臃肿就等于每次都在重复付费。缓存输入的成本约为新输入的 10%，所以让 Codex 复用上下文也比反复重新读文件划算。

## 付费版多出来的不只是额度

额度是最大的差异，但不是唯一的差异：

- **云端任务委派**（Plus 起）：从网页、GitHub、Slack 或 Linear 把任务丢进隔离沙箱并行执行，不占你本地机器，适合依赖升级、小 bug 批量修复这类可并行的活
- **GitHub 自动代码审查**：Codex 的 code review 能力会在 PR 从 draft 转 ready 时自动审查并在 PR 下留言，也可以用 @codex review 手动触发，甚至指定“重点看安全漏洞”这类方向
- **团队管理与用量控制**：Business 的管理控制台、Enterprise 的共享积分池，都是围绕多人协作设计的

这些能力的重心在云端基础设施和团队协作上，也是 Business、Enterprise 这类团队计划的核心卖点——不是免费档靠省着用能替代的东西。

## 不订阅行不行：API key 按 token 付费

第三条路线是完全跳过订阅。用 API key 跑 Codex CLI，按 token 计费；GPT-5-Codex 在 API 上与 GPT-5 同价，目前仅通过 Responses API 提供。

参考成本：GPT-5.3-Codex 的 API 价格是每百万输入 token $1.75、每百万输出 $14，按这个费率，一次典型 CLI 会话大约花 $0.50 到 $2。第三方按官方费率测算过临界点：如果每月会话次数不到 10 到 40 次，API 通常比 $20 的 Plus 更省钱；用量更低时，甚至比 $100 档还便宜。

代价也要清楚：走 API 拿不到 GitHub 自动代码审查、Slack 集成这类订阅功能，新模型一般也先向订阅用户开放。用得少是省钱，用得多反而贵。

## 常见问题

### Codex 免费版能写真实项目吗？

能，日常的小改动没问题。但免费额度很紧，让它通读整个代码库做重构这类重活，很快会撞到上限。把它当成试用通道更合适。

### 升级后本地和云端的额度是分开的吗？

共用一份。本地会话和云端任务从同一个池子里扣，云端跑得多了，本地窗口的余额也会跟着变少。

### 换更重的模型，额度消耗差多少？

差距是数量级的。以 Plus 为例，Luna 档每个 5 小时窗口估 250–2000 条本地消息，Terra 是 25–200，Sol 只有 10–100。日常小活让 Codex 用默认轻档，大重构前再手动切重档。

### GPT-5.5 退役，订阅用户需要做什么？

10 月 14 日起 GPT-5.5 从所有计划退役。如果你的 Codex 设置里还保存着 GPT-5.5，记得切换到 GPT-5.6 系列，免得任务跑不起来。
